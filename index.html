Für alle Geräte speichern

Die Anordnung wird als layout.json im GitHub-Repository gespeichert. Alle Geräte zeigen sie dann nach etwa 2 Minuten (Seite neu laden).

Token anlegen (einmalig, etwa 1 Minute)
  1. Auf GitHub einen neuen „Fine-grained token“ anlegen.
  2. Repository access: „Only select repositories“ → smarty-soundboard.
  3. Permissions: „Contents“ → Read and write.
  4. „Generate token“, Token kopieren und oben einfügen.

Der Token bleibt nur in diesem Browser gespeichert und darf nur dieses Repository ändern.
