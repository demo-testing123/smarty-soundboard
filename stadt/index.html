    Bauaufträge (manuelle Variante)

    Für die Show: Im Finale „Minecraft-Welt erstellen“ – die Datei enthält die Stadt mit allen übernommenen Beschlüssen, Start draußen am Platz. Die Bauaufträge unten sind nur für Änderungen von Hand in einer schon geöffneten Welt (Knopf im Regieraum oder Befehl im Chat).

    Neu beginnen?

    Alle Beschlüsse, Vorschauen, Mehrheiten und die Kamera werden zurückgesetzt. Die Stadt ist danach wieder grau – für eine neue Vorlesung. Eine schon erstellte Minecraft-Datei bleibt, wie sie ist; für die nächste Gruppe eine neue Welt erstellen.
